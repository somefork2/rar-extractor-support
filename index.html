RAR Extractor

Support for the Mac app that opens forty-one archive formats.

Getting help

Open an issue on GitHub — it needs no account details beyond a GitHub login, and every message is read. Please say which macOS version you are on and, if an archive will not open, what made it; that is usually enough to find the answer.

Questions that come up

An archive will not open.
The format is worked out from the file's contents, not its name, so a wrong extension is not the problem. If the file was downloaded, check it arrived whole: Tools ▸ Test Integrity reads every file through and names anything damaged.
Can it create RAR archives?
No. The unrar licence permits reading RAR archives but not creating them. The app writes ZIP, TAR, TAR.GZ, TAR.BZ2, TAR.XZ and TAR.ZST.
The right-click menu is not in the Finder.
macOS asks you to switch the extension on once: Settings ▸ Finder ▸ Open Extension Settings, then tick RAR Extractor.
Why does it ask for a folder when extracting?
The app is sandboxed. Opening an archive grants access to that one file, so the first time it writes into a folder it asks for that folder through the standard panel, and remembers the answer. Settings ▸ Privacy lists the folders you have allowed and can revoke any of them.
Where do archive passwords go?
Into your login keychain, if you ask the app to remember one. Never to us, never into a file. Settings ▸ Privacy can forget them all.
How do I look inside without unpacking?
Select a file in the window and press Space, or press Space on an archive in the Finder. To take one file out, drag its row straight to the Desktop.

What it reads
